# SimpleLogViewer

A simple JavaFX application for parsing and viewing large log files. It provides features to easily load, view, and filter log entries.

*Note: Development of this project is currently frozen.*

## Features

*   Load and parse large log files.
*   Display log entries in a clear, table-based format.
*   Filter logs by level (ERROR, WARN, INFO, DEBUG, TRACE).
*   Filter logs by thread.
*   Filter logs by a specific time range.
*   View detailed information for each log entry.

## How to Run

1.  **Prerequisites:**
    *   Java Development Kit (JDK) 8 or higher
    *   Apache Maven

2.  **Build and run the application using Maven:**
    ```bash
    mvn clean javafx:run
    ```

## Technologies Used

*   **Java**
*   **JavaFX** - For the graphical user interface.
*   **Maven** - For project build and dependency management.
